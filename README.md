# ISP Billing & Management System

A modern, full-stack ISP billing system built with React, Node.js, Express, and PostgreSQL. 
Designed for ISPs in Bangladesh, featuring MikroTik RouterOS integration, automated billing, and Bengali/English UI support.

## Project Structure
- `/docs`: Master documentation files (Single Source of Truth for AI and Developers)
- `/database`: SQL schemas, migrations, and seed data
- `/backend`: Node.js + Express API, Prisma ORM, MikroTik integration
- `/frontend`: React + Vite + Tailwind CSS application
